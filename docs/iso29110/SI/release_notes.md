# Release Notes

## Releases

```markdown
## vX.Y.Z — YYYY-MM-DD

### Summary
Brief description of the release.

### New Features
- [REQ-xxx] Feature description

### Bug Fixes
- [BUG-xxx] Fix description

### Breaking Changes
- Description of breaking changes

### Test Results
- Unit: X/Y passed
- Integration: X/Y passed
- Coverage: XX%

### Known Issues
- Issue description
```
